# Flask Web App

A simple web application built with Python and Flask, using HTML and CSS for the frontend and SQLite for data storage.

## 📌 About

This project was created to practice building a web application using Flask.

The application uses Flask to handle the backend and routes, HTML and CSS to create the user interface, and SQLite to store and manage data.

## ✨ Features

- Flask-based backend
- HTML and CSS frontend
- SQLite database integration
- Dynamic web pages
- User input and form handling
- Data storage and retrieval
- Simple and interactive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- JavaScript (minimal)
